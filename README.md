# VLM Research Wiki

A structured, expandable knowledge base for Vision-Language Model (VLM) research, initially focused on Video Quality Assessment, datasets, models, and reproducible experiments.

## View locally

Open `index.html` in a browser. This is a static HTML/CSS/JavaScript site; no build step is needed.

## Project rules

Before editing or adding content, read [`AGENTS.md`](AGENTS.md). It defines the research standards, directory structure, naming rules, page templates, navigation requirements, and acceptance checklist.

## Add a new research item

1. Read `AGENTS.md`.
2. Use the corresponding template in `papers/`, `datasets/`, `models/`, or `experiments/`.
3. Add the page in the matching directory using a lowercase kebab-case filename.
4. Update the matching category `index.html` and relevant cross-links.
5. Verify sources, links, responsive layout, and the acceptance checklist.

## GitHub Pages

In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The published URL will be shown by GitHub.

## Research integrity

Do not invent bibliographic details, dataset statistics, model capabilities, benchmark scores, or experiment results. Clearly distinguish source-reported facts from our own analysis and unverified information.
